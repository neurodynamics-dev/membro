Validação de documentos

Conferência da autenticidade dos documentos emitidos eletronicamente pelo SOMA, o sistema de gestão da NeuroDynamics PD&I.

1. Consultar documento

Informe o código verificador impresso no rodapé do documento — ou leia o QR Code com a câmera do celular, que abre esta página com o código já preenchido. Para a conferência completa, informe também o código de controle.

O código verificador tem 12 caracteres, em três grupos de quatro. As letras I, L, O e U não são usadas.

2. Resultado da consulta

Sobre a validação

  1. Os documentos emitidos pelo SOMA dispensam assinatura: a autenticidade se confere aqui, pelo código verificador.
  2. Esta página mostra o que foi impresso no documento na data da emissão. Qualquer diferença entre o papel e a tela indica que o documento foi alterado depois de emitido.
  3. O código de controle é calculado sobre o conteúdo do documento: se o informado não confere, o documento não é o que foi emitido.
  4. Um documento pode ser revogado depois de emitido — por exemplo, quando o registro que o originou é corrigido. A consulta informa a revogação e o motivo.

Por proteção de dados pessoais (Lei nº 13.709/2018), o CPF aparece parcialmente mascarado. A NeuroDynamics PD&I não guarda cópia dos arquivos emitidos: guarda o que foi impresso, o código e a data.
