# Fontes de impressão

Archivo, licença SIL Open Font License 1.1 em `Archivo-OFL.txt`.
Origem: `@fontsource/archivo` 5.2.8, arquivos Latin WOFF, pesos 400/700 normal/itálico. Conversão para TTF com fontTools (`TTFont`, `flavor=None`, `save`). Os nomes e metadados originais são preservados. `fontes-pdf.js` carrega e registra essas quatro variantes no jsPDF; nenhum CDN é necessário para as fontes de impressão.
